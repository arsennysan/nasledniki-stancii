# Публикация Наследников на Vercel

Готовая статическая версия игры. Supabase и переменные окружения не требуются.

## Публикация
Из этой папки выполните:

```powershell
npx vercel login
npx vercel --prod
```

Выберите свой аккаунт и создание нового проекта. Vercel прочитает vercel.json: Framework — Other, сборка отключена, выходная папка — dist.

После публикации используйте production-домен проекта (*.vercel.app). Проверьте его в приватном окне без входа в Vercel. Если появляется требование авторизации, проверьте Settings → Deployment Protection и доступ production-развёртывания.

Прогресс хранится в браузере. На новом домене сохранение со старого адреса автоматически не переносится. Общих аккаунтов, облачных сохранений и мультиплеера здесь нет.
