# Наследники станции — Карантин

Браузерная игра на JavaScript и Canvas: бои, генетика вымышленных существ, скрещивание, убежище и постоянный прогресс.

## Обновление 04
- Девять боевых комнат в трёх секторах, двери с четырёх сторон и переход камеры. Вход — с противоположной стороны.
- Выбор маршрута: обычный бой, элита, лаборатория мутаций или торговый пост. Каждый третий бой — босс.
- Игра занимает экран браузера. Экипаж, скрещивание, улучшения и достижения открываются в боковых панелях убежища.
- Видимые признаки гибридов, боевые мутации с преимуществами и недостатками, перегрев, разрушаемые ящики и предупреждения атак.
- Прогноз наследования шести локусов, сравнение геномов и родословная.
- 13 достижений, облики и стартовые бонусы. Поддерживаются старые сохранения v3.

## Запуск
Откройте `index.html` в браузере. Зависимости и сборка не требуются.

WASD / стрелки — движение, мышь — прицел, ЛКМ — огонь, пробел — рывок, E — способность. В убежище 1–5 открывают станции, F взаимодействует с терминалом. Esc / P — пауза или закрытие панели. Кнопка ⛶ включает системный полноэкранный режим.

## Публикация на Vercel
Импортируйте репозиторий в Vercel. Framework Preset — **Other**, Root Directory — корень репозитория, Build Command и Install Command — пустые, Output Directory — **`.`**. Настройки указаны в `vercel.json`.

HTML, CSS и JavaScript находятся в корне: папки `dist` здесь нет. Если проект Vercel уже создан, проверьте, что его настройки не переопределяют эти значения.

Supabase и переменные окружения не нужны. Сохранения находятся в localStorage и привязаны к браузеру и домену; между устройствами автоматически не синхронизируются.
